# Shape Visualization System

A Java desktop application for importing and visualizing geometric shapes.

## Technologies

- Java

- Java Swing

- Java AWT

- Object-Oriented Programming (OOP)

## Features

- Import shape data from text files.

- Visualize circles and cubes.

- Display the area of each shape.

- Navigate between imported shapes.

- Handle invalid file inputs.

## OOP Concepts

- Encapsulation

- Inheritance

- Abstraction

- Polymorphism

- Interfaces

## How to Run

1. Open the project in a Java IDE.

2. Compile the Java source files.

3. Run `project.ShapeViewer`.

4. Import `shapes.txt` using the application.
